Catatan prototype: Pengenalan suara menggunakan fitur browser (Web Speech API) dan paling baik di Google Chrome/Edge dengan koneksi internet serta izin mikrofon. Terjemahan memakai MyMemory tanpa API key, lalu mencoba Apertium bila pasangan bahasa tersedia. Kualitas dan ketersediaan layanan gratis dapat berubah. Untuk percakapan dua arah, masing-masing orang menekan tombol mikrofonnya saat berbicara; browser belum dapat memisahkan dua suara secara andal dari satu mikrofon. Hasil suara menggunakan suara Text-to-Speech yang tersedia di perangkat.
